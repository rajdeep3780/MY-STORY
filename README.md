# MY STORY 🌸

A small interactive story website built with HTML, CSS, and JavaScript.

## ✨ About

This project is a simple visual storytelling experience inspired by a few memorable moments.

It includes:

* 🌸 Animated story sections
* ☕ Coffee & 🍦 ice-cream themed visuals
* ✨ Smooth transitions
* 📱 Responsive design
* 💻 Simple HTML, CSS & JavaScript
* ⏳ A "Wait..." ending

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Google Fonts

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/rajdeep3780/MY-STORY.git
```

Open the project folder and launch `index.html` in your browser.
